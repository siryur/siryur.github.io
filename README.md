# siryur.github.io

Personal portfolio site for **siryur**, highlighting software engineering,
infrastructure, and technical leadership skills. Static HTML/CSS, served
via GitHub Pages at [siryur.com](https://siryur.com).

## Structure

- `index.html` — page content
- `styles.css` — styling
- `CNAME` — custom domain configuration

## Guidelines

This site intentionally does not reference real names, employers, or any
identifying personal information — content stays scoped to skills and
working approach.
